# 12306 抢票助手

基于 Selenium 的 12306 自动抢票工具，支持定时查询、自动下单、选座及邮件通知。  
首次扫码登录后，可保存登录记录，后续无需重复扫码。

## 目录结构

```text
12306自动抢票/
├── asset/                     浏览器驱动
├── core/                      核心代码
├── tools/                     辅助工具
├── utils/                     功能模块
├── data/                      扫码记录（自动生成）
├── config.yml                 配置文件
├── requirements.txt

├── 安装与更新依赖.cmd
```

## 环境要求

- Windows 10 / 11（64 位）
- Python 3.8 及以上，安装时勾选 “Add Python to PATH”
- Google Chrome

## 首次使用

### 1. 安装依赖与 ChromeDriver

双击 **安装与更新依赖.cmd**。

脚本将自动完成：

- 升级 pip
- 安装 requirements.txt 中的依赖
- 检测本机 Chrome 版本
- 从国内镜像下载并安装匹配的 ChromeDriver 到 `asset/`

若自动更新失败，可手动下载对应版本，放入 `asset/` 目录，并重命名为 `chromedriver.exe`。

### 2. 获取车站 Cookie 值

双击 **获取车站Cookie值.cmd**，输入车站中文名。

支持精确匹配与模糊搜索，查询结果自动复制到剪贴板。

将结果粘贴到 `config.yml` 的 `起点站` 与 `终点站`。

### 3. 编辑配置文件

双击根目录的 **config.yml**，用记事本打开编辑。

主要配置项：

| 配置项 | 说明 |
|---|---|
| `起点站` / `终点站` | 车站 cookie 值 |
| `购票日期` | 格式 `YYYY-MM-DD` |
| `开抢时间` | 格式 `YYYY-MM-DD HH:MM:SS`，建议设为放票前 1~3 秒 |
| `车次序号` | 按时间排序后买第几班，1 表示最早一班 |
| `乘车人` | 乘车人姓名列表，示例：`["张三"]` |
| `启用按乘客设置席别` | `true` 或 `false`，详见下方说明 |
| `席别` | 单个值或列表，可选：二等座 / 一等座 / 特等座 / 商务座 |
| `学生票` | `true` 或 `false` |
| `座位偏好` | 座位字母，留空表示不选座 |
| `启用邮件通知` | `true` 或 `false` |
| `发件邮箱` / `邮箱授权码` / `收件邮箱` | 邮件通知配置 |

其余为高级配置，一般无需修改。

#### 席别配置说明

**统一席别**（默认）：所有乘客使用同一个席别。

```yaml
启用按乘客设置席别: false
乘车人: ["张三", "李四"]
席别: ["二等座"]
```

**按乘客设置**：席别列表按顺序与乘车人一一对应，席别数少于乘客数时，多出的乘客使用最后一个席别。

```yaml
启用按乘客设置席别: true
乘车人: ["张三", "李四", "王五"]
席别: ["一等座", "二等座"]
# 张三 → 一等座，李四 → 二等座，王五 → 二等座
```

**注意**：订单中包含多种席别时，12306 不支持在线选座，座位由系统自动分配。

### 4. 启动抢票

双击 **开始抢票.cmd**。

程序会先询问登录方式：

- 若已有保存的扫码记录，可选择对应账号直接登录；
- 若选择扫码添加新记录，则打开 Chrome 扫码。

登录成功后，程序在 `开抢时间` 自动执行抢票，结果通过邮件通知（若已配置）。

## 注意事项

- 抢票过程中勿关闭浏览器窗口。
- 邮件密码需使用 SMTP 授权码，非登录密码。
- 运行日志位于 `app.log`。
- 扫码记录保存在 `data/cookies.json`，请勿分享或提交到 Git。
- 订单含多种席别时，无法使用在线选座。
- 若 ChromeDriver 版本不匹配，重新运行“安装与更新依赖”或手动替换。
